## [0.1.0] - 2026-07-04

### Added

- ADR generation from GitHub issue threads.
- Six ADR templates: default, Nygard, MADR, Alexandrian, Tyree-Akerman, and Y-Statement.
- DeepSeek backend for ADR drafting.
- GraphQL-based GitHub issue and comment fetch.
